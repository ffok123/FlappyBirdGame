# Flappy Bird Game

This project is a simple implementation of the classic Flappy Bird game using HTML, CSS, and JavaScript. The game features a jumping bird, obstacles in the form of pipes, a scoring system, and a restart function.

## Project Structure

```
FlappyBirdGame
├── assets
│   ├── bg.png
│   ├── bird.png
│   ├── char.png
│   ├── pipe_bottom.png
│   ├── pipe_top.png
│   └── restart.png
├── src
│   ├── index.html
│   ├── style.css
│   └── script.js
└── README.md
```

## Features

- **Jumping Bird**: The player can make the bird jump by pressing the spacebar.
- **Obstacles**: Pipes appear at random intervals, and the player must navigate the bird through them.
- **Scoring System**: Points are awarded for successfully passing through pipes.
- **Restart Function**: The game can be restarted after a collision.

## How to Run the Game

1. Clone the repository or download the project files.
2. Open the `src/index.html` file in a web browser.
3. Press the spacebar to start playing!

## Dependencies

This project does not require any external libraries or frameworks. It is built using standard web technologies: HTML, CSS, and JavaScript.
